# Changelog — August 31 – September 6, 2026

Welcome experience, language choice, and faster imports.

## ✨ New features

- **Example recipes on signup** — new accounts get suggested recipes to start with, so the app isn't empty on day one.
- **Choose your language on welcome** — pick your preferred language right from the welcome screen.
- **Shopping list display settings** — customize the shopping list UI from a new responsive settings drawer.
- **More AI choices, faster re-imports** — support for multiple AI providers/keys, and URL imports are now cached so re-importing the same link is instant.

## 🐛 Fixes

- **Profile settings save correctly again** — fixed the update-profile form.
- **Importing big pasted recipes on mobile** — no more layout jumping or text area overflowing the screen.
- **Recipe pages load faster** — fixed a double fetch on page load.
- Better small-phone layouts (edit-recipe page, general width fixes) and mobile navbar shortcuts.
- Fixed security warnings.

## 💅 Improvements

- New mobile screenshots on the landing page.
