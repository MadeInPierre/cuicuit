# Changelog — September 14–20, 2026

The foundations release: Cuicuit grew a public platform underneath the app.

## ✨ New features

- **Public REST API** — everything the app can do is now scriptable: recipes,
  plans, shopping lists, spaces, profile and seeds. Interactive schema at
  `/api/v1/openapi.json`. See `src/routes/api/v1/README.md` for the curl cookbook.
- **API tokens (`cui_…`)** — mint long-lived tokens for scripts and agents from
  `/api/v1/auth/tokens` (or the app), use them like a password, revoke anytime.
- **MCP endpoint for AI agents** — 37 tools at `/mcp` (Streamable HTTP): list plans,
  add recipes, check shopping items, import with seeds. `tools/list` works pre-auth.
  See `src/routes/mcp/README.md`.
- **Seed costs, simplified** — only recipe imports cost seeds (1 each, charged after
  success). The supporter wall no longer lists placeholder costs.

## 🐛 Fixes

- **No more silent no-ops** — editing or deleting something you can't access now
  returns a clear "not found or not accessible" error instead of fake success.
- **Recipe filters locked down** — only real filter columns are accepted, on every
  door (app, API and MCP share the same allowlist).
- **Safer payments** — Stripe redirect origin can be pinned via `CHECKOUT_ORIGIN`.
- **Space renames fixed** — renaming a space errored because `space_members` has no
  `id` column (caught by the new round-trip suite, not the type checker).

## 🧪 Testing

- **DB-backed round-trip suite** — `src/lib/core/operations/roundtrip.test.ts`: one
  real `runOp` per public op against local Supabase (RLS scoping, undo semantics,
  seeds/402 path, PAT lifecycle, cross-user denials, storage round-trips). Skips
  cleanly when local Supabase is down. This is the suite that makes the core
  "never break by surprise".
- **API↔MCP parity test** — every MCP tool's op has a REST route and vice versa.

## 🔧 For developers & agents

- New entrypoint: `docs/operations.md` — the 0→60 guide to adding an operation
  (`defineOp` once, exposed via app + API + MCP automatically).
- Direct database access outside `src/lib/core/` is now a lint error (one
  documented exception: the authz helper). Offline-sync design: `docs/sync-publication.md`.
