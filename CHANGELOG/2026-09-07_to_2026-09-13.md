# Changelog — September 7–13, 2026

Recipe search and shopping-list control, plus sturdier imports.

## ✨ New features

- **All recipe filters are here** — the recipe gallery now has the complete set of filters.
- **Custom ingredients** — add your own ingredients to a recipe, even if they're not in the catalog.
- **Search recipes on mobile** — the mobile recipe list finally has search.
- **Shopping aisles in your order** — set a custom display order for aisles in the shopping list.
- **Recipes without photos still look good** — an ingredient grid is shown as a thumbnail fallback.
- **Clearer on mobile** — the header now shows your active space icon instead of a generic avatar.

## 🐛 Fixes

- **Recipe page no longer crashes on repeated steps** — fixed a crash when two steps had the same text.
- **Imports survive hiccups** — if the AI returns partial data, we now still rescue the recipe URL, find a missing image URL, and tolerate empty fields instead of failing.
- **Aisle reordering that works** — replaced finicky drag-and-drop with simple, reliable buttons.
- Refined mobile navbar position and state bugs.
