# Changelog — August 3–9, 2026

Better imports and a smoother first experience.

## ✨ New features

- **Import from more sites** — multi-source recipe scraping means pasting a recipe URL works on many more websites.

## 🐛 Fixes

- **Recipe photos import correctly again** — fixed image upload breaking during recipe import.
- **Email verification that just works** — new verification page instead of a confusing link/endpoint, plus a fix for a crash caused by cookies.
- **Daily-use features stay available** — fixed a bug where features could lock you out when your credit balance was empty but the community pool wasn't.

## 💅 Improvements

- More consistent recipe carousel on all screen sizes.
- Small dark-mode polish.
